# 병원 내부용 급여계산 웹앱

지문출퇴근 엑셀, 직원마스터, 근무표, 인센티브 원본을 업로드해 직원별 월 급여를 세전 기준으로 계산하고, 예외 확인 후 급여를 확정하며 급여명세서를 Excel로 출력하는 로컬 실행용 MVP입니다.

## 기술 스택
- Frontend: React + TypeScript + Vite
- Backend: FastAPI + Python + SQLAlchemy
- Database: SQLite
- Excel: openpyxl / pandas

## 설치 방법
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cd frontend
npm install
```

## 실행 방법
터미널 1:
```bash
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```
터미널 2:
```bash
cd frontend
npm run dev -- --host 0.0.0.0
```
브라우저에서 `http://localhost:5173` 접속.

## 샘플 데이터 사용법
샘플 데이터는 `backend/sample_data/`에 있습니다.
```bash
python -m backend.app.seed
```
샘플 직원은 물리치료사 2명, 방사선사 1명, 간호조무사 1명, 의사 1명, 행정직 1명입니다.

## 엑셀 업로드 양식
### 근태 업로드
컬럼: `날짜`, `직원ID` 또는 `직원명`, `출근시간`, `퇴근시간`

### 통합 인센티브 업로드
컬럼: `날짜`, `직원ID` 또는 `직원명`, `직군`, `인센티브항목`, `세부항목`, `수량`, `타수`, `매출액`, `직접입력금액`, `환자명`, `비고`

### 공제 업로드
컬럼: `지급월`, `직원ID`, `국민연금`, `건강보험`, `장기요양보험`, `고용보험`, `근로소득세`, `지방소득세`, `기타공제`

## 급여계산 흐름
1. 직원과 근무표를 등록합니다.
2. 지문출퇴근 Excel을 업로드합니다.
3. 원본 출퇴근과 보정 출퇴근을 분리 저장합니다.
4. 예외내역에서 지문 누락, 중복, 근무표 없음 등을 확인합니다.
5. 인센티브 원본과 공제를 업로드합니다.
6. 월별 급여계산을 실행합니다.
7. 예외 확인 후 급여확정 버튼을 누릅니다.
8. 확정 후 수정은 `audit_logs`에 변경이력으로 저장됩니다.

## 충격파 인센티브 계산 방식
충격파는 총 타수 합산 방식이 아닙니다. 각 치료 건별 타수에 맞는 규칙을 먼저 찾아 금액을 계산한 뒤 직원별 월별로 합산합니다. 기본 샘플 규칙은 1000타=1,000원, 1500타=1,500원, 2000타=2,000원, 2500타=2,500원, 3000타=3,000원입니다. 규칙이 없는 타수는 예외내역에 `충격파 타수 규칙 없음`으로 기록됩니다.

## 도수치료 인센티브 계산 방식
도수치료는 관리자 규칙에 따라 매출비율, 건별고정금액, 직접입력금액 방식으로 계산합니다. 샘플은 매출액의 14%입니다.

## 예외내역 처리 방법
예외 화면에서 처리상태를 `미확인`, `확인완료`, `보정완료`, `제외처리`로 변경하고 관리자 메모를 남길 수 있습니다.

## 급여확정 방법
급여계산 화면에서 월을 선택해 계산 후 급여확정 화면에서 확정합니다. 확정 후 취소나 수정은 관리자 권한이 필요한 작업으로 API에 변경이력이 남습니다.

## 급여명세서 출력 방법
급여명세서 화면에서 지급월과 직원ID를 선택하면 Excel 급여명세서를 내려받을 수 있습니다. 포함 항목은 병원명, 지급월, 직원명, 직군, 지급/공제 항목, 총지급액, 총공제액, 실수령액, 계산방법, 비고입니다.

## 백업/복원 방법
관리자 설정의 백업 API는 SQLite DB 파일을 `backups/` 폴더로 복사합니다. 복원은 백업 파일명을 지정해 DB 파일을 교체합니다.
